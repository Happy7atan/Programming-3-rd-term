# Лабораторная работа №3. Построение бинарного дерева

Проект содержит рекурсивную функцию `gen_bin_tree`. Базовый результат
представлен словарями с ключами `value`, `left` и `right`. Алгоритмы
вычисления потомков можно передать как любые вызываемые объекты.

> **Вариант №11:** `root = 11`, `height = 3`,
> `left_leaf = lambda root: root ^ 2`,
> `right_leaf = lambda root: 2 + root ^ 2`.

## Требования

- Python 3.10 или новее;
- сторонние зависимости не нужны.

## Запуск

Построить и вывести дерево с параметрами варианта:

```bash
python binary_tree.py
```

Запустить тесты:

```bash
python -m unittest -v
```

В Google Colab тот же набор тестов можно запустить так:

```python
unittest.main(argv=[""], verbosity=2, exit=False)
```

## Пример использования

```python
from binary_tree import gen_bin_tree

tree = gen_bin_tree(
    height=3,
    root=10,
    left_leaf=lambda value: value - 1,
    right_leaf=lambda value: value + 1,
)
```

Переданные аргументы имеют приоритет над значениями варианта. Как и в
примере преподавателя, высота измеряется в рёбрах: при `height=0` дерево
состоит только из корня, при `height=1` — из корня и двух потомков.
Отрицательные значения считаются ошибкой.

В вариантах 5, 8, 11, 12 и 17 знак `^` понимается как математическое
возведение в степень, поэтому в Python используется оператор `**`. Оператор `^`
в Python выполняет побитовое исключающее «или» (XOR).

## Другие контейнеры

Для исследования альтернатив реализован `BinaryNode` на базе
`collections.namedtuple`. Функция `to_namedtuple` рекурсивно преобразует словарное
дерево, не изменяя его.

| Контейнер | Преимущества | Недостатки |
| --- | --- | --- |
| `dict` | Простой, наглядный, легко сериализуется | Ключи можно опечатать, узлы изменяемые |
| `namedtuple` | Поля доступны по имени, узлы неизменяемые и компактные | Для изменения нужно создавать новый узел |
| `dataclass` | Явные типы полей, удобно добавлять методы | Нужен отдельный класс; не из `collections` |
| Обычный класс | Полный контроль над инвариантами и поведением | Больше служебного кода |

Для обхода дерева по уровням удобен `collections.deque`, но очередь хранит только
порядок обхода, а не связи «родитель — потомок», поэтому она не заменяет узлы.
